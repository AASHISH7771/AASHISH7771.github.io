# Kura - Nepali <-> English translator

A hold-to-talk translator for visitors to Nepal. Runs entirely in the browser.

## What is here
- index.html, styles.css, app.js, phrases.js, translit.js - the app
- manifest.json, sw.js, icons - installable PWA + offline support
- .well-known/assetlinks.json - lets the Android APK open fullscreen

No build step. No server. Nothing to install.
